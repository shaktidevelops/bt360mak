# Battrick Raw Files Dropzone

Drop any saved HTML or text files from your Battrick club here:
- `players.asp` or `squad.html` -> Squad & 11 Skills
- `playerdetails.asp` -> Individual player career stats
- `office.asp` or `club.html` -> Club overview, divisions, morale, fan mood, ITS
- `finances.asp` -> Balance, gate receipts, weekly P&L
- `ground.asp` -> Stadium seating, pitch conditions
- `fixtures.asp` -> Match schedule
- `matchreport.asp` or `viewmatch.asp` -> Full scorecard, sector ratings, match summary
- `training.asp` -> Net allocations, Friday pop logs
- `diary.asp` / `calendar.asp` -> Manager diary and events
- `pavilion.asp` / `press.asp` -> Pavilion announcements, honours
- `staff.asp` -> Backroom staff directory
- `youth.asp` -> Youth academy stats

Files placed here can be ingested automatically into the live database.
